# my_fpml_wiki
個人的なFpML調査記録用のLLM-Wiki

Karpathy氏のLLM Wikiのコンセプトに基づいています。
https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f

このワークスペースは、ユーザーからのFpMLに関する質問に対するAI Agentの回答内容がWikiに反映されることで継続的に成長します。

```text
my_fpml_wiki/  (ワークスペースルート)
├── confirmation/            (Rawソース：FpMLのXSDとXMLサンプル)
├── fpml_xsd_catalog.md      (Rawソース：FpMLスキーマカタログ)
├── docs/
│   └── agents/
│       └── wiki.md          (LLMエージェントのWiki運用ガイドライン)
└── wiki/                    (Wikiルート)
    ├── index.md             (Wikiコンテンツカタログ)
    ├── overview.md          (Wikiの概要)
    ├── log.md               (Wiki更新ログ)
    ├── common/              (共通型・基盤ドキュメント)
    ├── products/            (プロダクト関連ドキュメント)
    ├── processes/           (業務プロセス関連ドキュメント)
    └── architecture/        (アーキテクチャ関連ドキュメント)
```
